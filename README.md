# 🛠️ Sistema de Gestão de Ordens de Serviço

Um projeto de **CRUD em PHP + MySQL**, desenvolvido com **arquitetura MVC**, focado na **gestão de ordens de serviço de manutenção**.

Este projeto foi criado com objetivo **educacional**, sendo ideal para quem está iniciando no desenvolvimento web e deseja aprender na prática conceitos como **CRUD, MVC, banco de dados, organização de código e boas práticas em PHP**.

---

## 📌 Sobre o Projeto

O sistema permite realizar o gerenciamento de **Ordens de Serviço (OS)** de manutenção, possibilitando o cadastro, edição, consulta e remoção de informações de forma simples e organizada.

A aplicação foi construída utilizando **PHP puro**, **MySQL** e uma estrutura baseada no padrão **MVC (Model-View-Controller)**, separando regras de negócio, interface e acesso aos dados.

### Funcionalidades

✅ Cadastro de Ordens de Serviço  
✅ Listagem de registros  
✅ Edição de informações  
✅ Exclusão de registros  
✅ Busca e consulta de dados  
✅ Organização do projeto em MVC  
✅ Integração com banco de dados MySQL
